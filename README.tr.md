# CapsLockNotifier
[English](README.md) · **Türkçe**

CapsLock, NumLock ve ScrollLock tuşlarını izleyen ve durumları değiştiğinde bildirim gösteren bir Windows sistem tepsisi uygulaması.

## İndir

[Son Sürümü İndir](https://github.com/Norethion/CapsLockNotifier/releases/latest)

## Özellikler

- CapsLock, NumLock, ScrollLock bildirimleri
- Özelleştirilebilir temalar (koyu/açık)
- Özel arka plan ve metin renkleri
- Bildirim konumu ayarları (6 konum)
- Ayarlanabilir bildirim süresi
- Türkçe/İngilizce dil desteği
- Windows ile başlatma seçeneği
- Çoklu monitör desteği

## Gereksinimler

- Windows
- .NET Framework 4.7.2 veya üzeri

## Kullanım

1. Sürümler sayfasından `CapsLockChecker.exe` dosyasını indirin
2. Uygulamayı çalıştırın
3. Ayarlara erişmek için sistem tepsisi simgesine sağ tıklayın
4. Tuşların mevcut durumlarını görmek için sistem tepsisi simgesine sol tıklayın
